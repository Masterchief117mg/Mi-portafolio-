# 🚀 Portafolio Web Personal - Kevin Fernández

¡Bienvenido al repositorio de mi portafolio personal! Este es un sitio web responsivo desarrollado completamente desde cero para mostrar mis proyectos, habilidades y perfil profesional como Desarrollador de Software Junior.

## ✨ Características Destacadas

Este proyecto no utiliza plantillas y fue construido enfocándose en el rendimiento y la experiencia de usuario (UX):

- **Diseño Isométrico 3D (CSS Puro):** Implementación de una laptop renderizada en 3D utilizando transformaciones complejas de CSS (`rotateX`, `rotateY`, `perspective`), sin uso de imágenes externas.
- **Efecto de Escritura (Scroll-linked):** Lógica en JavaScript (Vanilla JS) que analiza el porcentaje del scroll y simula la escritura de código en tiempo real dentro de la laptop.
- **Sticky Scroll:** Control del flujo de la página para que la sección principal se mantenga fija mientras ocurren las animaciones, liberando al usuario cuando finalizan.
- **Efectos Cibernéticos:** Luces de "red neuronal" usando pseudo-elementos, desenfoques (`blur`) y animaciones dinámicas (`@keyframes`).
- **100% Responsivo:** Diseño adaptable (Mobile-First) usando CSS Grid y Flexbox para asegurar que se vea perfecto en cualquier pantalla.

## 🛠️ Tecnologías Utilizadas

- **HTML5:** Estructura semántica.
- **CSS3:** Variables, Animaciones, Transformaciones 3D, Diseño Responsivo.
- **JavaScript (ES6):** Manipulación del DOM, Eventos de Scroll, Lógica matemática de renderizado.
- **FontAwesome:** Iconografía.
